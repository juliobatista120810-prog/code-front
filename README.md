# 💻 Exercícios de Codificação Front-End — SENAI Florianópolis

Este repositório foi criado com o objetivo de **armazenar, organizar e documentar** todos os exercícios, desafios e projetos práticos desenvolvidos durante as aulas de desenvolvimento Front-End no **SENAI Florianópolis**. 

O repositório funciona como um portfólio de evolução técnica, cobrindo desde os fundamentos da web até a construção de interfaces dinâmicas e responsivas.

---

## 🚀 Tecnologias e Ferramentas Utilizadas

O aprendizado é focado nas principais tecnologias do ecossistema Front-End:

* **HTML5:** Estruturação semântica de páginas web.
* **CSS3:** Estilização, layouts modernos (Flexbox/Grid), responsividade (Media Queries) e animações.
* **JavaScript (ES6+):** Manipulação do DOM, consumo de APIs, lógica de programação e interatividade.
* **Ferramentas de Desenvolvimento:** [Visual Studio Code](https://visualstudio.com), Git e GitHub para controle de versão.

---

## 📂 Estrutura do Repositório

O projeto está organizado por módulos ou tópicos de aprendizado para facilitar a navegação:

```text
├── 01-fundamentos-html/     # Primeiros passos com tags estruturais e semântica
├── 02-estilizacao-css/       # Exercícios de seletores, box model, Flexbox e Grid
├── 03-javascript-basico/     # Lógica, variáveis, funções e eventos
├── 04-javascript-avancado/   # Consumo de APIs (Fetch/Axios), Async/Await e JSON
├── 05-projetos-integradores/ # Projetos completos unindo todas as tecnologias
└── README.md                 # Documentação principal do repositório
```

## 🛠️ Como Executar os Projetos Localmente

Se você deseja testar qualquer um dos exercícios na sua máquina local, siga os passos abaixo:

1. **Clone o repositório:**
   ```bash
   git clone https://github.com
   ```
2. **Navegue até a pasta do exercício desejado:**
   ```bash
   cd nome-da-pasta-do-exercicio
   ```
3. **Abra o projeto:**
   * Você pode abrir diretamente o arquivo `index.html` no seu navegador.
   * Ou, caso use o VS Code, utilize a extensão **Live Server** para rodar um servidor local dinâmico.
